Conference ticket generator

A sign-up form that turns a person's details into a conference ticket.

  • HTML
  • CSS
  • JavaScript
The challenge
Build a form that generates a ticket, with plenty of room to customize the ticket and add a personal touch.
What I built
I built a dark, gradient-backed form with an avatar drag-and-drop upload area, fields for name, email and GitHub username, and a clear file-size hint. On submit, the details are used to generate the ticket.
What I learned
Practiced form handling, input validation and file upload with JavaScript, and styling a layered background.

Browser extension manager UI

A card-based manager for turning browser extensions on, off, or removing them.

  • HTML
  • CSS
  • JavaScript
The challenge
Build an interface for managing extensions that practices dynamic data, filtering, color theming and a responsive grid.
What I built
I built a responsive grid of extension cards, each with a toggle and a remove button. Filter buttons switch between All, Active and Inactive, and a theme button switches between light and dark.
What I learned
Practiced rendering a list from data, filtering it, and updating the interface when state changes.

Typing speed test

A timed test that measures words per minute and accuracy.

  • HTML
  • CSS
  • JavaScript
The challenge
Build a typing speed test that calculates words per minute (WPM) and accuracy, to practice DOM manipulation and timers.
What I built
I built a dark, distraction-free test that shows the passage, a running timer, live WPM and accuracy, and a personal best. Players pick a difficulty (easy, medium, hard) and a mode (60-second timed or a full passage), and can restart at any time.
What I learned
Practiced DOM updates, timers and live calculations, and saving a best score.
